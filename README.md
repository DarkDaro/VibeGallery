# VibeGallery

Полностью офлайн-галерея локальных видео для Windows в духе классического
медиаплеера: библиотека с миниатюрами, тегами, коллекциями, плейлистами,
умными фильтрами и поиском. Современный интерфейс на Electron.

## Основное

- Никакой телеметрии и сетевых запросов в рантайме: приложение
  работает только с локальными файлами.
- Библиотека хранится в SQLite (`%APPDATA%\VibeGallery\library.db`
  с автоматическим бэкапом при обновлении схемы).
- Видео открываются через внутренний протокол `media://`, доступ к файлам
  жёстко ограничен по путям библиотеки.
- Удаление файлов только в корзину, с подтверждением.
- Интерфейс: русский и английский, темы светлая/тёмная/системная.

## Разработка

Требуется Node.js 24+.

```powershell
npm install        # зависимости (включая загрузку ffmpeg/ffprobe)
npm run dev        # запуск в режиме разработки
npm run build      # typecheck + production-сборка
npm run dist       # NSIS-инсталлятор и portable-сборка
npm test           # unit-тесты (миграции, репозитории)
npm run e2e        # Playwright-тесты окна приложения
npm run lint       # ESLint
```

Тестовые видеофайлы для разработки: `npm run fixtures:gen`.
Скачивание ffmpeg/ffprobe: `npm run fetch:ffmpeg`.

## Структура

```
electron/   main-процесс: окно, БД, IPC, протокол media://, сервисы
shared/     контракты, общий для main и renderer
src/        renderer: React + Tailwind + Zustand
tests/      unit (Vitest) и e2e (Playwright)
scripts/    служебные скрипты установки и фикстур
```
